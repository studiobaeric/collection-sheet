# Code.gs / Ui.html contract for the Import agents (generated from the core build, 2026-10-15)

## Code.gs public API (UI-callable)
- getUiConfig() -> {conditions: [{code, label}] (8 entries incl. {code:'', label:'ohne Angabe'}, then MT 'Mint', NM 'Near Mint', EX 'Excellent', GD 'Good', LP 'Light Played', PL 'Played', PO 'Poor'), langs: [{code, label}] (11, LANGS order, DE first), versions: [distinct non-empty Sonderversion texts in Daten, sorted de], extras: extraNames_(), viewExtras: getViewExtras_()}
- addCard(req) req={id, lang:'de'|'en' (data language), variant:'base'|'reverse'|'firstEdition', condition, qty, inputName, cardLang (physical, default 'DE', also accepts 'Deutsch'/'en'), version (default ''), ownPrice (number | '1,50' text | null | '')} -> {eid, key, gkey, count (Hand row count after add), message}. Merges into the Hand row with the same entry key (computed from fields) or creates it (origin 'Hand', fp ''). An ownPrice > 0 is written to ALL rows of the group with today's date (null/'' leaves own price unchanged). Updates the trend price on all rows with the same id+variant. Message names language (e.g. 'Englisch') and version when not default; ' Eigener Preis: 2,50 €.' or ' (kein Preis)'. Invalid ownPrice text throws 'Bitte einen gültigen Preis eingeben, z. B. 1,50.'
- addFreeCard(req) req={name (required, else throws 'Bitte einen Namen eingeben.'), setName, number (e.g. '012/50', split into localId '012' + setSize 50), variant ('normal' default; normal|holo|reverse|firstEdition), condition, qty, cardLang, version, ownPrice} -> {eid, key, gkey, count, message}. Hand row with source 'frei', id '', no image, price ''. Key 'frei:<lower name>~<lower set>~<normalized number>|variant|version|cond|LANG'
- searchCollection(query, setText) -> {total (matching groups), groups: [...max 60]}. Group: {gkey, id, name (without version), nameEn, source, isFree, setName, localId, setSize (number|null), variant, variantLabel, version, count (sum), image, price (effective number|null), priceManual (bool), ownPrice (number|null), priceDate ('yyyy-MM-dd' own price date or trend priceDate), exemplare ('2× DE, 1× DE NM, 1× EN LP'), rows: [{eid, key, cond, lang, count, origin ('Hand'|'Import n'), originLabel ('von Hand' | '<Quelle>, Import n' | 'Import n'), isImport, importNr (number|null), extras: {name: text for every extra column}}]}. Groups sorted: count>0 first, setDate, setId, numSort, localId, variant, version, name. Rows: Hand first, import nr, lang (LANGS order), cond (CONDITIONS order). Text words match name/nameEn/version, number tokens match normNum (+setSize with '/'), setText matches setName substring, setId, or set-cache names (de/en).
- adjustEntry(eid, delta) -> {token: {eid, applied, logIds: [], createdEid: ''}, eid (row actually changed), count, groupCount, applied, gkey}. delta>0 on an import row goes to the Hand row with the same entry key (created as copy: new eid, origin Hand, fp '', count 0, extras + ownPrice copied; createdEid set). delta<0 floors at 0; on an import row with copies removed appends a 'handentfernt' log row (Import-Nr from origin, Quellzeile = row fp, Menge = removed, Quelle-ID from Importe, Daten {countBefore}) and returns its id in token.logIds. Unknown eid throws 'Eintrag nicht gefunden. Bitte die Liste neu laden.'
- revertAdjust(token) -> {eid, count, groupCount, gkey}. count -= token.applied (floor 0), deletes token.logIds log rows, deletes the token.createdEid row if it is back to 0. Missing row -> {eid, count:0, groupCount:0, gkey:''}
- editEntry(eid, changes, qty) changes={cond?, cardLang? (alias lang), version?, extras?: {name: value}} (only given fields change; unknown extra names create the column), qty = copies to change (default all; 1..count, larger is capped; <1 throws) -> {ok: true, eid (resulting row), gkey}. qty<count splits (new row: new eid, same origin, fp and added date). If a key field changed and another row has the same new key AND same origin AND same fp, counts are merged into it and the edited row disappears (Hand rows merge with the Hand row of the key). Invalid cond throws 'Unbekannter Zustand ...'.
- setGroupOwnPrice(gkey, price) price number>0 or text '3,10' sets ownPrice (rounded to cents) + ownPriceDate today on all rows of the group; null/''/0 clears -> {gkey, price (group effective price afterwards or null), priceManual}. Unknown gkey or invalid text throws.
- linkFreeGroup(gkey, cardId, dataLang 'de'|'en', variant 'base'|'reverse'|'firstEdition' (also normal/holo)) -> {gkey (new)}. Fetches the card (en fallback for image/price), sets card fields on all rows of the free group (name only replaced for 'de'), keeps cond/lang/version/count/origin/fp/extras/ownPrice, recomputes keys, merges Hand rows into an existing Hand row with the same key (own price carried over if the target had none). Throws if the group is unknown, already linked, or the card is not found.
- setViewExtras(names) names = array of extra column names -> {viewExtras: [kept names]} (only existing extra columns, distinct). Rebuilds Gruppen and the Sammlung header/formula, keeps B4:H4 controls.
- getSetSuggestions() -> [set names] (unchanged)
- searchCards(input) / getCardDetail(id, lang) / getCardBySetNumber(setId, number) unchanged
- kartenErfassen(): sets the sheet up first when needed (setupAll_: migrateSchema_ first, then sheets, setupImportSheets_ hook, Gruppen, view, triggers; otherwise repairSetup_ recreates missing sheets and triggers), then HtmlService.createTemplateFromFile('Ui'), t.mode='sidebar', evaluate().setTitle('Pokémon-Karten'), showSidebar
- doGet(): template 'Ui' with t.mode='web', setTitle('Pokémon-Sammlung'), viewport meta
- include(name) -> HtmlService.createHtmlOutputFromFile(name).getContent(), or '' when the file is missing
- Menu/trigger functions (not for google.script.run use): onOpen, onEdit(e) (Daten edit -> rebuildGroups_ with tryLock(5000), skipped silently when busy or schema not v2; Sammlung H4 -> row heights), ansichtNeuAufbauen, preiseJetztAktualisieren, uebersetzungUndSetsAktualisieren, apiPruefen (steps 1-14), webAppLinkAnzeigen, naechtlicherPreislauf, continuePriceRun

## Code.gs helpers for Import.gs
- Constants: SHEETS = {view:'Sammlung', data:'Daten', groups:'Gruppen', sets:'Sets', tr:'Übersetzung', hist:'Verlauf', check:'API-Check', imports:'Importe', proto:'Import-Protokoll'}; COL (0-based Daten indexes key..fp, see SPEC §1); NCOL = 30; DATA_HEADERS (30); PROTO_HEADERS; GROUP_HEADERS (23); ORIGIN_HAND = 'Hand'; LANGS [[code,label]...]; CONDITIONS ['', 'MT', ...]; CONDITION_LABELS; VARIANT_LABELS; SCHEMA_VERSION = '2'; MAX_CANDIDATES = 24; EUR_FORMAT
- ensureSchema_() -> void. Cheap check of property SCHEMA_VERSION, else migrateSchema_() (takes the lock). Call first in every public Import function, OUTSIDE withLock_.
- withLock_(fn) -> fn() result. Script lock with tryLock(30000) (German error when busy) and SpreadsheetApp.flush before release. Do not nest it and do not fetch inside it.
- newEid_() -> 'E' + 10 lowercase hex (from the last 10 hex of Utilities.getUuid()); newLogId_() -> 'L' + 10 hex
- originOf_(nr) -> 'Import ' + nr; importNrOf_(origin) -> number | null; isHandOrigin_(origin) -> true for '' or 'Hand'; normOrigin_(origin) -> 'Hand' or trimmed origin
- entryKey_(o | row) -> [head, variant, version, cond, LANG].join('|'), where head is the tcgdex id or 'frei:' + lower(trim name) + '~' + lower(trim setName) + '~' + normalizeNumber_(number before '/'). o = {id, name, setName, localId|normNum, variant, version, cond, lang}; lang is normalized by langCode_ (default 'DE'); a Daten row array also works.
- groupKey_(o | row) -> [head, variant, version].join('|'). keyHead_(o) -> the head alone; freeNum_(s) -> number text before '/'; keyFields_(row) -> key object from a row.
- langCode_(x) -> 'DE' for ''/'de'/'Deutsch'; unknown codes upper-cased. langLabel_(code). condCode_(x) -> valid upper-case condition code or null (''=no condition is valid). versionText_(x) -> whitespace-collapsed trimmed text.
- parsePrice_(x) -> number | null (empty) | NaN (unreadable). Handles '1,50 €', '1.50', '€ 1,5', '1.234,56', '1.234'.
- dateText_(x) -> 'yyyy-MM-dd' (Date, ISO text or timestamp); dmyText_(x) -> 'dd.MM.yyyy' from Date or 'yyyy-MM-dd' text; todayText_() -> 'yyyy-MM-dd'; cellText_(v) -> text with Dates as yyyy-MM-dd
- dataHeaders_() -> full Daten header array (DATA_HEADERS + extra headers from index 30, trailing blanks trimmed); extraNames_() -> non-empty extra names
- ensureExtraColumn_(name) -> 0-based column index. Appends the header (bold) and '@' format if missing; throws German error for empty names or names equal to a fixed header. Call inside the lock.
- deleteExtraColumn_(name) -> bool. sh.deleteColumn of that extra (inside the lock). Later columns shift, so call it after rewriteData_.
- rowObj_(row, headers?) -> {key, id, ..., fp, extras: {name: value}} (missing as ''). objToRow_(o, width?, headers?) -> row array of max(width, NCOL, headers.length); extras placed by header name, unknown names ignored. Pass headers in loops to avoid sheet reads.
- buildCardRow_(card, opts) -> full-width Daten row. card = summarizeCard_-like {id, name, nameEn?, setId, setName, setDate, localId, setSize, img|image, rarity, category, illustrator, baseVariant, variant?, price (number), priceDate, dataLang|lang 'de'|'en', inputName?} or {free:true, name, setName, localId ('012/50' allowed)}. opts = {variant ('base' or missing -> card.variant -> card.baseVariant -> 'normal'), cond, lang (default DE), version, count (default 1), origin (default 'Hand'), fp, ownPrice (number|text; >0 kept, rounded to cents), ownPriceDate (default today when ownPrice is set), extras {name:value} (columns must exist), now (Date for added/changed), eid (pre-assigned eid), headers, width}. Sets key = entryKey_; source 'de' | 'en-Ersatz' | 'frei'; en data: name = inputName or card name, nameEn = card name.
- readData_(sh) -> rows below the header, each padded to max(NCOL, sh.getLastColumn()) (may include blank rows; filter with isDataRow_(r))
- appendDataRows_(rows) -> void. One setNumberFormats + setValues after the last row (rows padded, columns and rows ensured). Inside the lock.
- rewriteData_(rows) -> void. Replaces all data rows in one write (blank rows dropped) and clears leftovers below. Use it for deletes. Inside the lock.
- dataStore_() -> st = {sh, headers, width, rows, base, dirty, removed}: in-lock working copy. storeAdd_(st, row) -> index; storeTouch_(st, i) marks a changed row; storeRemove_(st, i); storeLive_(st, i); storeFindEid_(st, eid) -> i | -1; storeFindHand_(st, key, exceptIdx) -> Hand row whose computed entryKey_ === key, or -1; storeGroupIdx_(st, gkey) -> [i]; storeGroupCount_(st, gkey) -> sum; storeEnsureExtra_(st, name) -> col (widens st). storeSave_(st) -> rewriteData_ if any loaded row was removed, otherwise writes dirty rows in contiguous blocks and appends new ones.
- rebuildGroups_() -> number of groups. Recomputes the hidden sheet Gruppen (23 columns + VIEW_EXTRAS) from Daten and repairs rows via repairRows_ (eid, lang, origin, key). Idempotent. Call after every Daten change, preferably inside the lock.
- getViewExtras_() -> [names] (property VIEW_EXTRAS); setViewExtras_(names) -> kept names. Lock-free: sets the property (existing extras only), rebuilds Gruppen and the Sammlung layout with controls kept. Use inside the import lock, e.g. setViewExtras_(getViewExtras_().concat(newNames)).
- groupPrice_(rows) -> {price, manual, ownPrice, ownDate, date}: first numeric ownPrice (Hand rows first, then by added), else first numeric trend. collectionValue_(rows) -> {total, cards, noPrice} like Sammlung. exemplareText_(rows) -> '1× DE NM, 1× EN LP'. orderGroupRows_(rows) -> Hand first, then added. groupRows_(rows, skip?) -> [{gkey, idx: [row indexes]}] in first-appearance order. isDataRow_(r).
- protoSheet_() -> Import-Protokoll sheet (created hidden with headers and formats). appendProto_(entries) -> [logIds]; entries = [{nr, type, eid, fp, qty, data (object, stored as JSON), status (default 'erledigt'), sourceId, logId? (pre-assigned), time?}]; one write; inside the lock. readProto_() -> [{logId, nr (number|null), type, eid, fp, qty (number), data (parsed, {} on error), status, time, sourceId, row (1-based)}]. deleteProtoByIds_(ids) -> count deleted (<=5: deleteRow each, else one rewrite). setProtoStatus_(ids, status) -> count changed (one column write).
- importInfo_() -> {nr: {nr, sourceName, sourceId, status}} read by header names Nr, Quelle, Quelle-ID, Status from sheet 'Importe' ({} if missing). originLabel_(origin, info) -> 'von Hand' | '<Quelle>, Import n' | 'Import n'.
- Sheet helpers: ss_(), sheet_(name) (German error if missing), getOrCreateSheet_(ss, name), writeHeaders_(sh, headers) (ensures columns, bold, frozen row), ensureCols_(sh, n), colLetter_(n), setupDataSheet_(ss)

## Notes from the core and integration agents
- Import.gs must call ensureSchema_() at the start of each public function, outside withLock_, because it may take the lock itself. withLock_ must never nest: inside a lock use setViewExtras_ (not setViewExtras), and do not call other public API functions.
- The tests use a stub for ImportUi.html and load only Code.gs. Once Import.gs and ImportUi.html exist, run 'IMPORT=1 IMPORTUI=1 node test_integration.js'; with the real ImportUi the impInit-count check is relaxed.
- For the Import.gs agent: Apps Script loads .gs files in one global scope, so Import.gs must not redeclare Code.gs top-level consts and must not read them in top-level code (file load order can cause a temporal-dead-zone (TDZ) ReferenceError). It must call ensureSchema_() outside withLock_ and use setViewExtras_ (not setViewExtras) inside its lock.

## Notes from the UI agent for ImportUi
- Format note for ImportUi: the UI global LANGS is [{code, label}] (the getUiConfig shape), not Code.gs's [['DE','Deutsch'], ...] pairs. CONDITIONS is an array of codes with '' first, and labels live in CONDITION_LABELS.
- ImportUi.html should run no server calls at load time, only from impInit(). It is included in web mode too.
- After importCommit, importUndo or setViewExtras, ImportUi should call loadUiConfig() so that UI_CONFIG.extras and versions (Bearbeiten fields, version datalist) are current.
